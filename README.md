# IS201 Final Project - Lot Holmstead's Personal Website

Welcome to my final project for IS201! This repository contains the source code for my personal website.

## 🌐 Overview
This website serves as a digital portfolio and a showcase of my web development skills. It was built using HTML, CSS, JavaScript, and Bootstrap.

## 🚀 Features & Pages
- **Home (`index.html`)**: A landing page introducing who I am, featuring links to my social profiles and other sections of the site.
- **Resume (`resume.html`)**: A digital copy of my professional resume, highlighting my experience, education at Brigham Young University, and skills.
- **Snowboarding / Scratch Page (`scratch.html`)**: A page dedicated to my passion for snowboarding. It includes facts, media, and an interactive **Tableau Data Visualization** dashboard.
- **My App (`app.html`)**: A custom interactive web app called "Snowboard Ride Coach." By inputting today's weather conditions or your trick goals, the app provides a quick and tailored riding plan using JavaScript logic.

## 🛠️ Built With
- **HTML5** for structure
- **CSS3 / Bootstrap 5** for styling and responsive design
- **JavaScript** for interactivity (specifically in the Snowboard Ride Coach app)
- **Tableau** for data visualization

## 📂 Project Structure
- `index.html`, `resume.html`, `scratch.html`, `app.html` - Main pages of the website.
- `css/` - Contains the custom stylesheets (`styles.css`, `scratch.css`).
- `js/` - Contains the JavaScript logic for the site and the custom app.
- `images/` - Contains all media, photos, and icons used throughout the project.
